## 🚀 Featured: PayBox Tribunal

**If the API doesn't keep its promise, the agent doesn't pay.**

Pay-on-validation for [x402](https://www.x402.org/): the AI agent's payment is verified but only settled after the response is judged against the seller's published contract (schema → objective rules → AI judge). Built for the MoonPay PayBox hackathon.

- ✅ Settled with real USDC on **Solana mainnet** and **Base**
- 🛡️ 40 paid calls, **19 broken promises blocked**, $0 charged for failures
- 🧾 Promises written in plain language, compiled into deterministic / heuristic / probabilistic checks
- 🔏 Every verdict signed with Ed25519 and verifiable offline
- 🔌 MCP plugin for PayBox agents

[**Repo**](https://github.com/Exoticdevelopment/paybox-tribunal) · [**Live demo: try to break it**](https://paybox-tribunal.onrender.com) · [**Video**](https://x.com/usuariomgz/status/2111476389648257384)
